Application Java permettant de gérer les employés, les projets et les missions d'une entreprise en utilisant la programmation orientée objet (POO).
Concepts utilisés

Classes abstraites

Héritage

Polymorphisme

Association entre classes

Association réflexive

Tableaux d'objets

Classes

Employe : classe abstraite des employés

Ingenieur : calcul du coût selon le niveau d'expertise

Commercial : calcul du coût avec une prime

Projet : gestion des projets

Mission : gestion et calcul du coût des missions

Main : programme principal
